# Офлайн-сводка прокси FBref (#1339)

`FBREF_CAMOUFOX_BLOCK_SCRIPTS` по умолчанию блокирует обычный JS до admission.
Явное `0` возвращает загрузку JS. Cloudflare/Turnstile разрешены прежним
allow-guard; HTML-документы, в том числе таблицы в комментариях, сохраняются.
Keep-alive уже доступен через `FBREF_PERSISTENT_HTTP_SESSION=1`; менять его
при доставке можно только по регламенту источника. GeoIP остаётся одним bounded
lookup на аренду, без межарендного кеша.

Сводка работает только с локальными файлами, без доступа к источнику:

```bash
python3 scripts/report_fbref_proxy_waste.py \
  --ledger saved-paid-ledger.jsonl --boundaries saved-boundaries.json
```

Ledger — сохранённые события `paid-proxy-v2` proxy filter. Границы — JSON с
периодом и явным списком аренд выбранного контура, включая ошибки и хвосты:

```json
{
  "start": "2026-10-28T00:00:00+00:00",
  "end": "2026-10-29T00:00:00+00:00",
  "lease_ids": ["lease-example"],
  "warmup": [{
    "lease_id": "lease-example",
    "start": "2026-10-28T00:00:00+00:00",
    "end": "2026-10-28T00:01:00+00:00"
  }]
}
```

Границы прогрева берутся из сохранённых снимков фаз, а не угадываются по
хосту. Интервалы включают начало и исключают конец; время обязательно с timezone.
Без `warmup` его числитель, знаменатель и процент равны `null`, статус —
`no_data`. Пустой список означает известное отсутствие прогрева. При нулевом
знаменателе процент также `null`.

Числитель CF — точные `bytes` входящих и исходящих событий для `cloudflare.com`
и его поддоменов. Это определение по хосту, не оценка всех байтов, обработанных
Cloudflare на домене FBref. Первый знаменатель — все байты выбранного контура,
второй — только байты внутри интервалов прогрева. Сводка показывает обе доли,
числители, знаменатели, период и список аренд. Исторические проценты не зашиты.
Полноту ledger и списка аренд должен обеспечивать подготовленный evidence bundle;
отчёт не проверяет подпись и не доказывает полноту исходных данных.

Офлайн-тесты сравнивают инвентарь с table ID, availability, строками и ячейками
при обоих значениях флага. Match — сохранённый HTML, schedule — сохранённый
фрагмент, season — явно синтетическая страница с таблицами в DOM и комментарии
(`tests/fixtures/fbref/proxy_waste/season.html`). Настоящего сохранённого season
HTML с таблицами в доступных фикстурах нет; tableless season не используется
как доказательство успешного браузерного прогрева.
Модель DOM применяет заданный эффект ресурса только после разрешения маршрута;
проверка наличия таблицы читает получившийся DOM. Отрицательные тесты отвергают
страницу без таблиц и страницу, где таблицу создаёт заблокированный JS.
Это ограниченная модель, не выполнение реального JS в браузере и не проверка
прохождения живого challenge или всех зависимостей сохранённых страниц от JS.

**Приёмка #1339 заблокирована отсутствием сопоставимых замеров трафика.**
Экономия ≥20% требует сопоставимых замеров всего контура до/после при одинаковых
страницах и инвентаре, включая прогрев, ошибки и хвосты. Таких замеров в этом
worktree нет; синтетические числа и размеры HTML не заменяют измерение трафика.
Выкат и платная канарейка требуют отдельного решения владельца.

Parser version, batch identity и `FETCHER_VERSION` сохранены: применяется
существующий переключатель ресурсов без изменения контракта парсера и учёта
транспорта. Изменение runtime-файла должно учитываться штатной проверкой
fingerprints при разрешённой доставке; пломбы здесь не обновляются.
