# Критерии готовности и стадии сдачи

Критерий конкретной задачи берётся из её согласованных условий, issue и действующего
handoff. Текущий фокус платформы — Bronze. Готовность Bronze-задачи не требует
включать Silver/Gold; готовность всей цепочки до витрин проверяется отдельной задачей.
Этот документ не меняет предметные контракты, бюджеты и полномочия источников.

| Стадия | Нужное доказательство | Что ещё остаётся |
| --- | --- | --- |
| Код проверен | Точный diff/SHA, затронутые проверки, требуемый полный unit suite, отдельное ревью без существенных замечаний; для docs — ссылки/загрузка, для инструкций — новая сессия | PR, обязательные CI и разрешение на merge по процессу задачи |
| Код слит | Merge SHA, выполненные обязательные CI и защита ветки | Доставка и эксплуатационная приёмка, если они входят в задачу |
| Доставлен | Автомат/регламент источника подтвердил фактическую версию и fingerprints runtime | Проверка данных и поведения после доставки |
| Принят | Согласованные критерии задачи выполнены на доставленной версии; доказательства прогонов, качества, свежести и полноты за требуемое окно | Обновление handoff, issue и доски по факту |

Для DAG приёмка включает метабазу Airflow: `last_parsed_time` после доставки,
отсутствие своих import errors и результаты требуемых прогонов. Успешный CLI DagBag
или merge сам по себе этого не подтверждает. Количество прогонов и окно наблюдения
задаёт контракт источника/issue, а не универсальный новый порог.

Если задача заканчивается на проверенном PR или документации, production-приёмка
не добавляется автоматически. В финальном отчёте явно назови достигнутую стадию,
проверенное, непроверенное и следующий обязательный шаг.

При ожидаемой приёмке после merge используй `Refs #N` вместо `Closes #N`/`Fixes #N`.
Issue и Project остаются открытыми до выполнения её критерия; merge не означает Done.
Сам PR не даёт разрешения на merge или ручную доставку. Известный baseline-сбой
не даёт права обходить гейты.

[PROD-CHECKLIST](PROD-CHECKLIST.md) сохраняет историческую матрицу готовности всей
платформы до Gold. Её оценки и даты не являются текущим статусом источников.
Актуальные точки входа и runbooks — в [индексе](README.md).
