# FBref Bronze — архив ревью, 12 сентября 2026

**Bronze FBref не принят в production.** В проверенном окне все 19 завершённых плановых current-запусков упали, история остановилась 6 сентября. Три исправления кода и исправление теста подготовлены и проверены offline; код не доставлен. Подготовка реализации остановлена пользователем. Следующий этап — несколько ревью, затем новые дочерние задачи под единым эпиком.

Это публичный архив материалов ревью для [data-platform-football](https://github.com/sergeykuznetsov1995/data-platform-football). Он сохраняет выводы, источники, измерения и ограничения исходных отчётов. Полный кодовый patch и исходные внутренние доказательства сохранены только локально и недоступны по GitHub-ссылке на этот пакет. Удалённый пакет содержит выбранные отчётные материалы, а не полный аудит всех production-данных.

Согласованные уточнения в [agreed-scope.md](agreed-scope.md) заменяют прежние допущения исходных отчётов. Закрытие старых issues при консолидации означает перенос обсуждения и материалов, а не завершение исправлений. Архивный план не является активной очередью исполнения.

В пакет не включены raw HTML, production backups, дампы БД/API, зеркала конфигурации или исходников, скрипты и кодовые патчи. Внутренние адреса, пути и сведения доступа удалены. Repo-relative source paths, публичные GitHub/FBref ссылки, source IDs и проверяемые хэши сохранены там, где они объясняют вывод. Существующие исходные отчёты не изменялись.
